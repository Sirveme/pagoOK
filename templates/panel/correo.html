Cómo reenviar desde Gmail

  1. En Gmail (desde la computadora) entra a Configuración (el engranaje) → Ver toda la configuración → pestaña Reenvío y correo POP/IMAP.
  2. Toca Agregar una dirección de reenvío, pega tu dirección de PagoOK y acepta.
  3. Gmail nos manda un código de confirmación: en unos segundos aparecerá arriba de esta página. Cópialo en Gmail y toca Verificar. No actives el reenvío de todo tu correo.
  4. Ahora crea un filtro: en la barra de búsqueda de Gmail toca el ícono de opciones, escribe en De la dirección desde la que te llegan las alertas del banco {% if estado.bancos_con_correo %}(por ejemplo: {% for b in estado.bancos_con_correo %}@{{ b.dominios[0] }} para {{ b.nombre }}{% if not loop.last %}, {% endif %}{% endfor %}) {% else %}(míralo en un correo de alerta de tu banco){% endif %} y toca Crear filtro.
  5. Marca Reenviarlo a, elige tu dirección de PagoOK y toca Crear filtro. Listo.

Cómo reenviar desde Outlook

  1. En Outlook entra a Configuración → Correo → Reglas → Agregar nueva regla.
  2. Condición: De → la dirección desde la que te llegan las alertas de tu banco.
  3. Acción: Redirigir a → tu dirección de PagoOK. Usa Redirigir, no "Reenviar": así el correo llega tal como lo mandó el banco y podemos comprobar que es auténtico.
  4. Guarda la regla.
